# Security

Atrium handles health data, so security reports matter.

## Reporting a vulnerability

Please do not open a public issue. Report privately through GitHub's
[security advisory form](https://github.com/Het-Bhavsar/Atrium/security/advisories/new), with:

- what is affected (pod firmware, case firmware, app, BLE interface);
- how to reproduce it;
- the impact you expect.

You will get an acknowledgement within a week. Fixes are released before details are published.

## Scope

- The BLE interface (pairing, bonding, log transfer, firmware update).
- Data stored on the phone and on the pod.
- Debug access on production units.
