# EasyEDA Pro project

`Atrium_EVT.epro2` is the native EasyEDA Pro project the boards were drawn in: the editable source for every schematic
and layout in `hardware/`. The `.SchDoc` and `.PcbDoc` files beside each board are exports of it.

| Board in the project | Released as |
|---|---|
| Radio_Island | `pod/radio-island/` |
| Power_Island | `pod/power-island/` |
| Flex_Jumper | `pod/flex-jumper/` |
| Pod_Islands_Panel | `pod/islands-panel/` |
| Charging_Case | `case/charging-case/` |
| zArchive_Pod_old_rev, zArchive_Case_old_rev | The superseded Rev B.1 pod and case (see `legacy/rev-b1/`) |

Open it in EasyEDA Pro 3.2 or later (desktop or [pro.easyeda.com](https://pro.easyeda.com)) by importing it as a project. It carries its own copies of every symbol, footprint and device, so it opens without the online
library. Exported with EasyEDA Pro 3.2.209.
