# Rev B.1 (superseded)

The first full design: a 28 × 14 mm stadium pod on a 0.6 mm four-layer board and a 40 × 26 mm two-layer charging case.
It was schematic-complete with simulations and enclosure CAD; it was never routed or built.

| Folder | Contents |
|---|---|
| `hardware/pod/schematic`, `hardware/case/schematic` | Schematic PDFs and pin-level netlists (CSV) |
| `hardware/pod/bom`, `hardware/case/bom` | BOMs with LCSC numbers |
| `hardware/pod/pcb`, `hardware/case/pcb` | Placement lists |
| `hardware/*/mechanical` | Shell, window, adhesive, cell and case parts as STEP, STL, 3MF and DXF |
| `hardware/simulation` | Optics Monte Carlo, signal budget, thermal and power results (JSON), SPICE netlists |
| `images/` | Illustrations from the Rev B.1 README |

See [`../README.md`](../README.md) for why it was replaced.
